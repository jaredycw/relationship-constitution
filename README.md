# 關係憲章 / The Relationship Constitution

Local-first charter for two people. Propose, dual-sign, amend, log, weekly sitting.

## 語言 Language

- `zh-HK` Hong Kong Traditional — default when the browser language starts with `zh`
- `en`
- Toggle at the top right. Preference is stored in `localStorage` key `relcon.v1`

Template clauses follow the UI language. Sentences you edit yourself are not rewritten.

## Open

No build step. Open `index.html`.

```
index.html
styles.css
i18n.js
app.js
```
